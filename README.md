## 📌 About This Repository  
This repository is a **complete Python learning guide** starting from **basic programming concepts** to **Object-Oriented Programming (OOP)**.  
It includes **well-documented code, notes, and examples** that make learning Python step-by-step and easy to follow.  

---

## 📂 Contents  

### 🔹 Basics of Python  
- Printing & Variables  
- Data Types (int, float, string, list, tuple, dict, set)  
- Operators (Arithmetic, Logical, Comparison)  
- Strings & String Formatting (`%`, `.format()`, f-strings)  
- Conditional Statements (`if`, `elif`, `else`)  
- Loops (`for`, `while`)  
- Functions and Docstrings  
- Arguments: `*args` and `**kwargs`  
- Global vs Local Variables  
- Error Handling (`try`, `except`, `finally`)  
- Modules (time, math, functools, glob, etc.)  
- Function Caching (`@lru_cache`)  
- Coroutines in Python  

---

### 🔹 Intermediate Python  
- File Handling (`open`, `read`, `write`, context managers)  
- With Statements (`with open(...) as f`)  
- Iterators & Generators  
- Decorators (`@staticmethod`, `@classmethod`)  
- Lambda Functions  
- Map, Filter, Reduce  

---

### 🔹 Object-Oriented Programming (OOP) Concepts  
- **Classes and Objects**  
- **Instance Variables vs Class Variables**  
- **Constructors (`__init__`) and `self` keyword**  
- **Class Methods** and Alternative Constructors  
- **Static Methods**  
- **Inheritance**  
  - Single Inheritance  
  - Multiple Inheritance  
  - Multi-level Inheritance  
- **Encapsulation**  
  - Public, Protected, Private variables  
- **Polymorphism**  
  - Method Overriding  
  - Operator Overloading  
- **Super() and Method Resolution Order (MRO)**  
- **Diamond Problem in Multiple Inheritance**  
- **Dunder (Magic) Methods**  
  - `__init__`, `__str__`, `__repr__`, `__add__`, `__len__`, etc.  
- **Abstract Base Classes (ABC module)**
