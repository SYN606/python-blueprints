# Object-Oriented Programming (OOP) Fundamentals

Object-Oriented Programming (OOP) encompasses several key concepts that form the foundation of designing and organizing code.  
The **four fundamental principles** are:


## ![Abstraction](https://img.shields.io/badge/Principle-Abstraction-blue)

**Definition:**  
Abstraction is the process of simplifying complex systems by modeling classes based on essential properties and behaviors, while ignoring non-essential details.  

**Key Points:**
- Focuses on *what* an object does, not *how* it does it.  
- Achieved using abstract classes and interfaces.  
- Provides a **blueprint** for objects.  


## ![Encapsulation](https://img.shields.io/badge/Principle-Encapsulation-green)

**Definition:**  
Encapsulation is the bundling of data and methods that operate on that data into a single unit known as a class.  

**Key Points:**
- Hides internal implementation details.  
- Exposes only necessary functionality.  
- Improves **security** and **organization** of code.  

## ![Inheritance](https://img.shields.io/badge/Principle-Inheritance-orange)

**Definition:**  
Inheritance allows a new class (subclass/derived class) to inherit properties and behaviors from an existing class (base/parent class).  

**Key Points:**
- Promotes **code reusability**.  
- Establishes **hierarchical relationships** between classes.  
- Supports **extensibility** by building on existing functionality.  


## ![Polymorphism](https://img.shields.io/badge/Principle-Polymorphism-purple)

**Definition:**  
Polymorphism refers to the ability of objects to take on multiple forms.  

**Key Points:**
- Objects of different classes can be treated as objects of a common base class.  
- Achieved through **method overriding** and **interfaces**.  
- Provides **flexibility** and **extensibility** in code.  


## 📝 Summary

These four principles collectively contribute to building **robust, modular, and maintainable software systems** using object-oriented design:
